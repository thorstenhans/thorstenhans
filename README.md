# Hi, I'm Thorsten 👋

I build serverless apps with WebAssembly and [Spin](https://spinframework.dev), and write about Rust, Wasm and Kubernetes at [thorsten-hans.com](https://thorsten-hans.com).

By day, I'm a Senior Developer Advocate at [Akamai](https://akamai.com), helping developers ship Spin apps on Kubernetes and at the edge.

## 📘 My Book

**[Building Serverless Applications with WebAssembly & Spin](https://www.amazon.com/dp/B0HNSDWXHT)** is a hands-on guide to building, composing and running serverless Wasm apps with Spin and Rust.

Get it on [Amazon](https://www.amazon.com/dp/B0HNSDWXHT) (paperback and Kindle) or [Leanpub](https://leanpub.com/building-serverless-apps-with-wasm-and-spin) (PDF and EPUB).
